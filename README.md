# 🚀 Lightweight DevOps Project

A lightweight DevOps project built using **Python Flask**, **Docker**, and **Docker Compose**.

This project demonstrates containerization, deployment, and basic DevOps workflows using modern tools.

---

# 📌 Features

- ✅ Python Flask Web Application
- ✅ Dockerized Application
- ✅ Docker Compose Support
- ✅ Easy Deployment
- ✅ Beginner Friendly DevOps Project
- ✅ Lightweight & Fast Setup

---

# 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| Python Flask | Backend Web Application |
| Docker | Containerization |
| Docker Compose | Multi-container Management |
| Linux | Deployment Environment |

# 🚀 How to Run the Project

## 1️⃣ Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/lightweight-devops-project.git
```

---

## 2️⃣ Navigate to Project Directory

```bash
cd lightweight-devops-project
```

---

## 3️⃣ Build & Start Application

```bash
docker compose up --build
```

OR

```bash
docker-compose up --build
```

---

# 🌐 Access Application

Open browser and visit:

```bash
http://localhost:5000
```

---

# 🐳 Useful Docker Commands

## Check Running Containers

```bash
docker ps
```

---

## Check All Containers

```bash
docker ps -a
```

---

## Stop Containers

```bash
docker compose down
```

OR

```bash
docker-compose down
```

---

## View Container Logs

```bash
docker logs <container_id>
```

---

# 📦 Manual Docker Build (Optional)

## Build Docker Image

```bash
docker build -t lightweight-devops-app .
```

---

## Run Docker Container

```bash
docker run -d -p 5000:5000 lightweight-devops-app
```
